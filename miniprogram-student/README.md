# 智慧宿舍管理系统 · 学生端微信小程序 (miniprogram-student)

基于微信小程序原生框架（WXML + WXSS + JavaScript）开发的智慧宿舍管理系统学生端，专为本科毕业设计答辩及真实业务体验设计，可直接导入微信开发者工具开箱运行，与后端 Spring Boot (7000端口) 深度联通。

---

## 一、 快速导入与运行步骤

1. 打开 **微信开发者工具**（若无 AppID，可选择「测试号」或直接使用内置游客模式）。
2. 点击 **「导入」** 项目：
   - **项目名称**：`miniprogram-student`
   - **目录**：选择本项目工程下的 `miniprogram-student` 文件夹（即包含 `project.config.json` 的目录）。
   - **AppID**：可填入您的微信小程序 AppID 或点击 **「测试号」**。
3. 检查本地网络设置：
   - 点击开发者工具右上角 **「详情」** -> **「本地设置」**。
   - 确保勾选 **「不校验合法域名、web-view (业务域名)、TLS版本以及HTTPS证书」**（`project.config.json` 中已默认配置 `urlCheck: false`）。
4. 确保后端 Spring Boot 服务已启动（默认端口 `7000`）。更新本次代码后需重新启动后端，晚归报备接口才会生效。
5. 微信开发者工具模拟器将自动渲染页面，即可正常登录使用。

宿管可使用宿管账号（演示账号 `dm01`，初始密码见下方说明）登录，进入访客核验工作台。扫描学生出示的访客通行码，或手动输入通行码，核对访客及楼栋信息；访客离开后点击「确认访客签离」。扫码核验本身不会自动签离，宿管只能操作自己管理楼栋的访客。需重新启动更新后的后端并重新编译小程序；相机扫码请在真机调试中验证。

> **真机预览提示**：
> 本地后端启动时（包括 IntelliJ IDEA、Maven 和项目启动脚本）会调用 Node.js 检测局域网 IPv4 并更新 `utils/config.js`。手机和电脑需连接可互通的同一网络，更新地址后需重新编译或重新发起真机调试。后端运行中切换网络时，可在项目根目录运行 `node scripts/configure-miniprogram.js`，或重启后端。Windows 防火墙需允许手机访问后端端口；多网卡时可设置 `SMART_DORM_IP` 为本机与手机同网段的 IPv4 后重启。真机请使用微信开发者工具的「真机调试」并按工具提示开启调试；普通预览和正式发布仍受微信域名及 HTTPS 等规则限制，自动配置局域网 IP 不能替代这些要求。

## 三、 功能特性全览

1. **首页我的宿舍**
   - 房态看板：已入住寝室号、床位号、楼栋信息、电费/水费余额（欠费预警高亮）与文明寝室评分。
   - 新生引导：待分寝新生三步走进度引导条，一键直达选宿问卷。
   - 待评价强提醒：报修工单完工后顶部横幅强提醒，闭环回访服务评价。
   - 同寝室友与契合度：展开查看室友、作息标签，并进入生活习惯对比。
   - 站内通知与未读消息：未读消息标为已读、公告详情半屏展示。
2. **六维生活习惯画像 (Habit)**
   - 问卷录入：作息时间、睡眠浅度、空调偏好、卫生标准、寝室氛围、异味敏感六个维度自评。
   - 动态雷达图：基于原生 Canvas 2D 高保真渲染学生特征向量多边形与寝室平均画像对比。
   - 标签云：支持预设爱好标签切换与自定义标签增补。
3. **故障报修 (Repair)**
   - 在线申报：电力、水暖、门窗桌椅、网络等类别，紧急关键词提示，支持上传现场照片。
   - 工单追踪：工单状态（待派单/维修中/已完工/已取消）、高危置顶与 SLA 承诺截止时间及超时标识。
   - 回访评价：完工后支持 1~5 星评星与满意度评语回传。
4. **水电服务 (Utility)**
   - 双账户管理：电费/水费独立账户余额展示。
   - 模拟充值：支持 ¥20/¥50/¥100/¥200 快速充值并生成唯一幂等请求号。
   - 账单核销：月度阶梯计价账单展示与一键余额核销。
   - 流水记录：充值/缴费 DEMO 流水号与水电余额变动。
5. **宿务综合大厅 (Affair)**
   - 文明寝室评比：当期星级评定和综合文明分。
   - 访客通行码 (`pages/visitor-pass/visitor-pass`)：登记来访信息，展示可编码 `VP-xxxxxx` 核验码的二维码。
   - 调宿与退宿办理 (`pages/adjust-apply/adjust-apply`)：联动楼栋与房间空床位，提交换宿或退宿申请。
   - 晚归报备与违纪申诉：登记晚归事由和预计归寝时间；对违纪晚归记录发起在线申诉。
   - 住宿业务申请 (`pages/residence/residence`)：入住报到登记、寒暑假留宿审批。

## 四、 目录工程结构

```
miniprogram-student/
├── app.js                         # 小程序入口逻辑与全局状态
├── app.json                       # 小程序页面与 TabBar 路由配置
├── app.wxss                       # 全局微回弹与精细化样式规范
├── custom-tab-bar/                # 悬浮主导航及页面选中状态
├── project.config.json            # 微信开发者工具工程配置（免域名校验）
├── sitemap.json                   # 索引配置
├── utils/
│   ├── config.js                  # 后端服务域名与接口地址配置
│   ├── api.js                     # wx.request Promise 封装与鉴权拦截
│   └── util.js                    # 时间、金额、生活习惯文本工具库
├── images/                        # 界面与导航线性图标
└── pages/
    ├── home/                      # 首页我的宿舍
    ├── habit/                     # 选宿生活习惯画像与 Canvas 2D 雷达图
    ├── repair/                    # 故障报修申报与工单列表/评分
    ├── utility/                   # 水电账户、充值模拟与账单明细
    ├── affair/                    # 宿务大厅、晚归报备与违纪申诉
    ├── login/                     # 学生与宿管账号登录
    ├── manager-visitor/           # 宿管扫码核验与访客签离
    ├── visitor-pass/              # 访客电子通行码
    ├── adjust-apply/              # 调宿与退宿在线申请表单
    └── residence/                 # 住宿业务与留宿申请表单
```

本地回归测试：在 `miniprogram-student` 目录执行 `node --test tests/contracts.test.js`。生活习惯页面可从首页的“我的室友”展开区域进入；待分寝学生可从首页“选宿画像”进入。
